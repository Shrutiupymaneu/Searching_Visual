# Searching Algorithm Visualizer

A fully functional and interactive **Searching Algorithm Visualizer** built using **HTML, CSS, and JavaScript**. This project helps users understand how different searching algorithms work through step-by-step visual animation.

## 🚀 Project Overview

Searching Algorithm Visualizer is a web-based project that demonstrates the working of searching algorithms in a clear and interactive way. The array elements are represented visually, and during the search process, each element is highlighted to show comparison, progress, and final result.

This project is useful for students, beginners, and anyone who wants to understand searching algorithms practically instead of only reading theory.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## ✨ Features

- Generate a new random array
- Search for a target value
- Linear Search visualization
- Binary Search visualization
- Automatic sorting for Binary Search
- Adjustable array size
- Animation speed control
- Step-by-step visual animation
- Clear result display
- Responsive and user-friendly interface

## 📌 Searching Algorithms Included

- Linear Search
- Binary Search
